This assignment practices loops, conditions, counting, and debugging.

grade_reporter.py - Uses a for loop and if/elif/else to calculate grades, pass and fail counts, and the average score.
bug_hunt.py - Finds and fixes three bugs in a while loop program that calculates the sum from 1 to 5.
The hardest bug to find was the while loop condition because it did not produce an error message. I knew something was wrong because the program ran but printed 10 instead of the expected answer, 15.
